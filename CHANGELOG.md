# Changelog

## v1.0.2

- Prepared the project for GitHub.
- Embedded the Viper snake icon into the Windows executable.
- Embedded the Woz Reaper header artwork into the executable as an assembly resource.
- Added GitHub Actions Windows build workflow.
- Added build, usage, security, publishing, and licensing documentation.
- Added `.gitignore` and `.gitattributes`.

## v1.0.1

- Improved local build script checks.
- Fixed problems caused by attempting to execute the build script from inside a ZIP archive.

## v1.0

- Initial Viper Disk Harvester release.
- Full Asimov recursive crawler.
- DSK, WOZ, PO, NIB, and HDV harvesting.
- Separate per-format destination directories.
- Retry, partial-file, and collision protection.
- Apple II hacker-themed Windows interface.
