# Licensing

This GitHub package intentionally does **not** select an open-source license on your behalf.

Without an explicit license, publishing the repository on GitHub does not automatically give other people permission to copy, modify, or redistribute the source beyond rights provided by law and GitHub's platform terms.

Common choices if you want others to use the code include:

- **MIT** — short and permissive.
- **Apache-2.0** — permissive with explicit patent terms.
- **GPL-3.0** — derivative distributed works generally need to remain under the GPL.

Choose the license that matches how you want the project reused, then add the corresponding `LICENSE` file before or after publishing.

The software's license is separate from the legal status of disk images found on third-party archives. Users remain responsible for what they download and redistribute.
